# Volatco Folding Pattern

Source dimensions from Volatco docs page:

- Board size: **6 cm x 4 cm x 1.5 cm** (60 x 40 x 15 mm)

Packaging dieline generated in:

- `volatco-folding-pattern.svg`

General dieline print area:

- Overall artwork footprint: **194 x 98 mm**
- Width: **194 mm**
- Height: **98 mm**

Palette standard (Cartheur logo aligned):

- Primary dark: **#101010**
- Accent mint: **#20F8A8**
- Neutral light support: **#EDF4F1**, **#DBE7E2**

Design decisions:

- Bubble wrap compensation: **3 mm per side** (anti-static protective wrap).
- Wrapped board footprint: **66 x 46 x 21 mm**.
- Internal box target: **68 x 48 x 23 mm** (adds 2 mm insertion clearance per axis).
- Largest visible areas (front + top) carry primary `VOLATCO` branding.
- Side panels retain vertical brand marks for shelf visibility.
